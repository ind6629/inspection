# 安卓安装与连接

生成文件：`Inspection-Android.apk`。应用为普通虚拟巡检，不使用真实 AR，不要求 ARCore。适用于 Android 8.0 及以上、ARM64 手机，横屏运行。

1. 将 APK 通过 USB、微信文件传输或同 Wi-Fi 下载传到手机，在手机文件管理器中打开安装。安装提示请由手机使用者自行确认。
2. 手机和运行 Go 后端的电脑连接同一 Wi-Fi。关闭旧的 Go 进程后，运行项目根目录 `start-backend-lan.cmd`，监听 8080。
3. 在电脑查看 Wi-Fi IPv4 地址。手机浏览器先访问 `http://<电脑Wi-Fi地址>:8080/health`，看到 `{"status":"ok"}` 后再打开应用。
4. 登录页“后端地址”填写 `http://<电脑Wi-Fi地址>:8080`，不能填写 localhost / 127.0.0.1。成功使用过的地址会保存在手机，下次可直接使用；电脑更换 Wi-Fi/IP 后需要重新填写。
5. 使用已有巡检员账号，或点击注册创建账号。管理员在电脑网页中管理问题和用户。

操作：左下方向键移动；拖动场景转动视角；轻点设备或表面放置标记；填写标题并上报。拖动、长按、方向键和界面按钮不会同时创建问题标记。表单打开时停止移动。

可运行 `start-apk-share.cmd`，手机在同一 Wi-Fi 访问 `http://<电脑Wi-Fi地址>:8090/Inspection-Android.apk` 下载。该服务只分享 android 目录，请在传输后关闭其窗口。

如果 health 无法访问，检查手机与电脑是否处于可互访网络、Wi-Fi 是否启用客户端隔离，以及 Windows 防火墙是否允许该 Go 服务接收局域网连接。不要关闭整个防火墙。当前构建为局域网 HTTP 演示，不是公网部署版本。

验证范围：项目编译、APK 签名/清单及电脑模拟触屏布局可在本机检查。没有连接 Android 手机时，不能声称已经完成真机安装、输入法和触屏实测。
